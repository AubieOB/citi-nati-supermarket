# Citi-Nati Supermarket System User Guide Index
 
 ## 1. Purpose
 
 This file is the master index for user-facing operating documentation.
 
 Use this file to choose the correct full guide by audience.
 
 ## 2. Audience split
 
 Use the storefront guide if the reader is a customer or customer-support operator.
 
 Use the admin guide if the reader is an internal staff user operating the admin dashboard.
 
 ## 3. Primary guides
 
 ## 3.1 Storefront and customer guide
 
 File: `STOREFRONT_CUSTOMER_USER_GUIDE.md`
 
 Covers:
 
 - all customer pages and routes
 - account/login/register flows
 - product browsing, search, category and sale filters
 - cart operations and minimum order handling
 - checkout and delivery validation
 - payment success verification and order tracking
 - common customer troubleshooting
 
 ## 3.2 Admin panel guide
 
 File: `ADMIN_PANEL_USER_GUIDE.md`
 
 Covers:
 
 - admin access and route entry
 - location-scoped operations
 - every admin sidebar panel
 - business operations tab suite
 - permission-gated behavior
 - daily operations SOP and troubleshooting
 
 ## 4. How to use this documentation set
 
 1. Identify user type: customer or admin staff.
 2. Open the matching guide above.
 3. Follow the page-specific procedures and checklists.
 4. For policy/legal references, use public policy pages in the storefront guide.
 
 ## 5. Document maintenance rule
 
 When functionality changes:
 
 1. update the affected detailed guide first
 2. update this index only if file names/scope changed
 3. keep both guides synchronized with production behavior
 
 ## 6. Related specialized guides
 
 This repository includes specialized technical/operational guides (POS sync, deployment, import/export, and testing).
 
 Those documents are complementary and do not replace the two primary user guides above.
